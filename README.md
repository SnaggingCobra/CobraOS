# CobraOS

CobraOS is a small desktop-style website that runs in your browser.

## Run

Open `index.html` in a browser. No installation or build step is needed.

## Features

- Desktop with a wallpaper, dock, clock, date, status icons, and calendar.
- Windows that can be moved, minimized, maximized, and closed.
- Browser for opening websites inside the desktop.
- Files for browsing folders and managing a simple file list.
- Notes that save in your browser.
- Music player for local audio files.
- Settings for theme, accent color, animations, and device status.
- Paint with color and brush controls, eraser, undo, clear, and PNG save.
- Calculator for basic arithmetic.
- Stopwatch with start, pause, and reset.

## Notes

- Notes, settings, and the file list are saved in browser storage.
- Files does not read or change folders on your computer.
- Some websites block display inside CobraOS's embedded browser.
- Battery information depends on browser support.

## Built With

HTML, CSS, and JavaScript. CobraOS has no backend.
